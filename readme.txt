✔ **Product Variation Images Gallery:**

With Easy Product Gallery, you can assign multiple images to each product variation. Unlike default WooCommerce (which supports only one image per variation), this feature allows you to display unlimited images for every variation.

When customers select options like Color, Size, or Style, the gallery updates instantly to show the correct images, helping users better understand the product and improving the shopping experience. 🚀

✔ **Product Video Gallery:**

Display product videos directly inside your gallery to make your products more engaging.

Add YouTube videos that play smoothly alongside product images within the gallery. Vimeo, Dailymotion, Facebook, and self-hosted videos are available in the Pro version. 🚀

✔ **Product Image Zoom:**

Add advanced zoom functionality to your product images. Customers can hover to see detailed views of textures, colors, and product elements.

Includes a standard hover zoom. Zoom Window, Zoom Lens, and Zoom Window Two styles are available in the Pro version. 🚀

✔ **Product Image Lightbox:**

Enable a clean and distraction-free lightbox experience. Users can open images in a full-screen popup and browse easily.

This improves user engagement and helps customers explore product details more effectively. 🚀

== Installation ==

1. Upload the `themewant-product-gallery` folder to the `/wp-content/plugins/` directory, or install the plugin via the WordPress Plugins menu.  
2. Activate the plugin through the 'Plugins' menu in WordPress.  
3. Navigate to the WooCommerce product page to see the enhanced image gallery.

== External Services ==

This plugin connects to the following external services. No data is sent to any of them on activation.

= Appsero (usage analytics) =

The plugin includes the Appsero SDK, which shows an admin notice asking whether you want to share non-sensitive usage data.

* If you click "Allow": the following is sent to Appsero once at opt-in and then once a week:
  * site URL and name
  * admin email and the first administrator's first and last name
  * WordPress, PHP, MySQL and server versions
  * locale, multisite status, active theme
  * user counts by role
  * number and list of active/inactive plugins
  * server IP address
  * plugin version
* If you click "No thanks": a single request is sent containing only an anonymous site hash (an MD5 hash of the site URL), so the notice is not shown again.
* When you deactivate the plugin: a feedback form is shown. When the form is submitted or skipped, the selected reason, any text you entered, and the site details listed above are sent to Appsero.

Data is sent to: https://api.appsero.com
Appsero Terms of Service: https://appsero.com/terms-policy/
Appsero Privacy Policy: https://appsero.com/privacy-policy/

= icanhazip.com (IP lookup) =

When Appsero collects the data above, it calls https://icanhazip.com/ to find the server's public IP address. That request reveals the server's IP address to the service. It is sent only together with an Appsero data submission (opt-in, the weekly report, or deactivation feedback).

Service: https://icanhazip.com/
Operated by Cloudflare. Terms: https://www.cloudflare.com/website-terms/ — Privacy: https://www.cloudflare.com/privacypolicy/

= YouTube (product videos) =

If you add a YouTube URL to a product image, the video is played from YouTube's privacy-enhanced domain (youtube-nocookie.com) in an embedded player or the lightbox, and the video thumbnail may be loaded from img.youtube.com. This happens only on product pages that have a YouTube video, when the visitor views or plays it. The visitor's IP address, browser information and the video ID are sent to YouTube/Google.

YouTube Terms of Service: https://www.youtube.com/t/terms
Google Privacy Policy: https://policies.google.com/privacy


== Frequently Asked Questions ==

= Is Easy Product Gallery compatible with my theme? =  
Yes, Easy Product Gallery is designed to work with most WooCommerce-compatible themes. 

= What does Easy Product Gallery do? =
Easy Product Gallery replaces the default WooCommerce product gallery with a modern, responsive image slider that supports images, videos, zoom, lightbox, and variation image galleries to create a better shopping experience. 

= Can I add multiple images for each product variation? =
Yes. Easy Product Gallery allows you to add unlimited images for each product variation such as color, size, or style. When customers switch variations, the gallery automatically updates to show the relevant images.

= Which video sources are supported in the product gallery? =
The plugin supports multiple video sources including YouTube, Vimeo (Pro), Dailymotion (Pro), Facebook (Pro), and self-hosted videos (Pro). Videos can be displayed alongside product images within the gallery.

= Can I customize how product videos appear in the gallery? =
Yes. You can choose Inline or Popup playback and customize the play icon size, color, and background. In the free version the play icon is shown in the middle of the video; Top Right, Top Left, Bottom Right, and Bottom Left icon positions are available in the Pro version.

= Does the plugin support product image zoom? =
Yes. The plugin includes hover zoom functionality that allows customers to inspect product details by hovering over images.

= What Product zoom styles are available? =
The plugin offers multiple zoom styles including: Standard Zoom, Zoom Window (Pro), Zoom Window Two (Pro), Zoom Lens (Pro). You can also customize the zoom lens appearance, overlay opacity, and zoom window settings.

= Does the plugin include a lightbox feature? =
Yes. The plugin includes a built-in lightbox popup that lets customers open product images in a larger view and navigate through them easily.

= Can I customize the Product Slider lightbox design? =
Yes. You can customize various lightbox options such as: Transition effects, Close icon color and background, Image captions, Image counter display, Icon positions

= Can I customize the gallery layout? =  
Absolutely! The plugin offers multiple layout options that you can configure to match your store’s design.  

= Does it support Product image zoom and lightbox? =  
Yes, the gallery includes zoom and lightbox functionality for a seamless viewing experience.  

= Does the plugin support 360° product view? =
Yes. You can display products in an interactive 360° image view popup, allowing customers to explore products from every angle.

= Can I control the position of the 360° view button? =
Yes. You can place the 360° popup button in different positions such as Bottom Left, or Top Left, Top Right and Bottom Right (Pro), and adjust the button offset as needed.
